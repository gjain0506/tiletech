# TileTech Website — V1

A responsive single-page catalogue website for TileTech.

## Files
- index.html — website structure
- styles.css — responsive styling
- script.js — product catalogue filtering and demo enquiry form

## GitHub Pages
Upload these files to the root of the `main` branch.

For `www.tiletech.in`, add a CNAME file containing:
www.tiletech.in

Then configure GitHub Pages for the repository.
